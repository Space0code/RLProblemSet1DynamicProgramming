# RL Problem Set 1: Dynamic Programming

Problem set for the Reinforcement Learning course: policy evaluation, value iteration and policy iteration on a controlled queue MDP.

- **Instructions:** [`problem1.pdf`](problem1.pdf)
- **Main notebook** (code, results and interpretations): [`QueueingExperiment.ipynb`](QueueingExperiment.ipynb)
- `QueueingEnvironment.py` (the MDP) and `QueueingPolicies.py` (policies and DP algorithms) are used by the notebook. Figures are saved to `figures/`.

To reproduce, run all cells of the notebook (requires `numpy` and `matplotlib`).
